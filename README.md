# Aroma & Mix - Menú Digital ☕

Menú digital interactivo, moderno y adaptado para dispositivos móviles y computadoras de escritorio, desarrollado para la cafetería **Aroma & Mix**.

## 🎨 Características Principales
- **Diseño Estético & Cálido:** Fondo color hueso (`#F4F1EA`) con tipografía moderna y amigable estilo *Fredoka* (inspirada en diseño artesanal).
- **Responsive & Multi-pantalla:** Vista en dos columnas para computadoras de escritorio y diseño optimizado de una sola columna para celulares.
- **Carrito de Compras Completo:** Gestión de ítems con contadores en tiempo real, cajón deslizable para móviles y panel lateral permanente en escritorio.
- **Flujo de Pedido Simplificado:** Botón directo de "Hacer Pedido" con notificaciones visuales (Toast).
- **Filtros Dinámicos:** Clasificación rápida por bebidas calientes y frías.
- **Asistente IA (Gemini):** Widget interactivo de recomendaciones de bebidas basadas en los antojos del cliente.
- **Sección FAQ:** Acordeones desplegables para preguntas frecuentes sobre pagos, envíos y opciones especiales.

## 🚀 Cómo desplegar en GitHub Pages
1. Sube todos los archivos de este repositorio a un repositorio nuevo en GitHub (por ejemplo, `aroma-and-mix`).
2. Ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. En el menú izquierdo, haz clic en **Pages**.
4. En la sección **Build and deployment**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)` como fuente (*Source*).
5. Haz clic en **Save**. ¡Listo! GitHub te generará un enlace público en pocos minutos para que tus clientes puedan ver el menú.
